Reference

Basics
tutorial — Match "tutorial" anywhere
^How — Starts with "How"
2024$ — Ends with "2024"
Character classes
[aeiou] — Any vowel
\d — Any digit
\w — Word character
\s — Whitespace
Quantifiers
a* — Zero or more "a"
a+ — One or more "a"
a? — Zero or one "a"
a{2,5} — 2 to 5 "a"s
Special
. — Any character
cat|dog — "cat" OR "dog"
/test/i — Case insensitive
Common examples
^(How|What|Why) — Questions
(react|vue|angular) — JS frameworks
ep(isode)?\s*\d+ — Episode numbers
^(?!.*shorts).*$ — Exclude "shorts"
Good to know
A pattern that doesn't compile is ignored — TubeFilter shows everything rather than hiding everything.
Regex mode uses the whole textarea as one pattern; the comma-separated keyword list is disabled.

Keyboard shortcut

Alt+Shift+F toggles filtering on the current tab without clearing your filters. Rebind it from chrome://extensions/shortcuts.

Language support

The view-count, duration and upload-date filters read YouTube's own metadata text and currently understand the English UI only. On other languages those three filters are skipped rather than guessed, so nothing is hidden by mistake. Keyword, regex and the Shorts / Live / Watched toggles work in every language.
